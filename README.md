# STRATA — 重ねて、隠して、4つ並べ。

1台のスマホを2人で挟んで遊ぶ、**記憶の立体四目並べ**。

- 赤・緑・青の3色のコマは**2人の共有**。自分の番に好きな色を選んで置く
- オセロのようなマス目に置き、同じマスには**上に積み重なる**
- カメラは盤を**真上から**見下ろしているので、**下に隠れたコマの色は見えない**
- **同じ色を4つ一直線に並べた人の勝ち**。縦・横・ななめ・積み上げ（タワー）・**階段状**・立体ななめ、の13方向すべてOK
- 誰が置いたコマでも、**4つ目を置いた人の勝ち**。相手にリーチを渡さない色選びと、隠れた色の記憶が鍵

プレイ: **https://muaaaa849.github.io/Tic-tac-toe/** （GitHub Pages を有効にした後）

## 遊び方

| 操作 | タッチ | マウス / キーボード |
| --- | --- | --- |
| 色を選ぶ | 手元の 赤 / 緑 / 青 をタップ | クリック、または `1` `2` `3`（`R` `G` `B`） |
| マスを選ぶ | タップ（なぞると追従） | ホバー、または矢印キー |
| 置く | 同じマスをもう一度タップ、または［置く］ | クリック、または `Enter` |
| 待った | 相手が置く前に［待った］ | `Z` / `Backspace` |
| メニュー | 手元の「…」 | `Esc` |

### スタイル（新しいゲーム画面で選択）

- **向かい合う**（スマホ推奨）: スマホを机に置き、2人が向かい合って座る。相手側の操作パネルと文字は自動で逆さま（横向きなら左右）に表示。パネルを渡す必要なし
- **手渡し**: 手番ごとにスマホを渡す。盤面は手番の人から見た向きに回転
- **並んで**: PCなどで横並びに座る

### UX の工夫

- 選んだマスの上にコマの「ゴースト」が浮かび、影と着地リングで高さが分かる。誤操作を防ぐ2タップ確定（マウスはホバー＋クリック）
- 着地の物理アニメーション、合成した効果音（木の盤・金属どうしで音が違う）、振動（Android / iOS 18+）
- 直前の一手のマーカーと「相手は 青 を 2段目 に置いた」表示で、記憶の手がかりを1回だけ残す
- 各マスの段数表示（設定でOFF可）、満杯マスは理由をトーストで説明
- 決着時はカメラが斜めに回り込み、積み上げたコマが**分離して隠れていた色がすべて露わ**になる。勝ちラインは光のビームで表示し、ドラッグで盤を回して確認できる
- 対局は自動保存（リロードしても「続きから」）、画面スリープ防止、ホーム画面追加でオフラインでも遊べる（PWA）
- 色覚サポート（▲●■ の印）、`prefers-reduced-motion` 対応、画質の自動調整

## 技術

- [three.js](https://threejs.org/) r187（`vendor/three/` に同梱、ビルド不要）
- フォトリアル表現: PBR マテリアル（ラッカー塗りのウォールナット盤・真鍮の象嵌グリッド・旋盤加工のガンメタル・クリアコートの宝石）、テクスチャはすべて実行時に手続き生成
- 真上視点用に設計したスタジオ環境マップ（真上を暗く、斜めにソフトボックス）＋ソフトシャドウ
- コンポジット: MSAA → Bloom → ACES トーンマップ → 自作合成パス（色収差・ビネット・スプリットトーン・フィルムグレイン）
- 描画は必要なときだけ（電池にやさしい）。遅い端末では解像度を自動で下げる

```
index.html            エントリ（import map で three.js を読み込み）
css/style.css         UI（合成レイヤー）
src/game.js           ルール（純粋なロジック、13方向の勝利判定）
src/scene.js          3Dシーン・カメラ・アニメーション・ポストプロセス
src/textures.js       手続き生成テクスチャ
src/audio.js          合成効果音・振動
src/howto.js          遊び方スライドのイラスト
src/main.js           画面遷移・入力・UI
sw.js                 オフライン用 Service Worker
tests/game.test.mjs   ルールのテスト
```

## 公開（GitHub Pages）

1. このブランチを `main` にマージ（またはこのブランチをそのまま使う）
2. リポジトリの **Settings → Pages → Build and deployment** で
   **Source: Deploy from a branch**、ブランチと **/ (root)** を選んで保存
3. 数分後に `https://muaaaa849.github.io/Tic-tac-toe/` で遊べます
